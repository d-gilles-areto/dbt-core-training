# Aufgabenstellung Exercise 06

## Ziel

Dokumentiere das bestehende dbt-Modell strukturiert in YAML und nutze dbt Docs zur Qualitätskontrolle inkl. Lineage.

## Aufgaben

1. Ergänze Layer-Tags für Staging, Core und Marts in der Projektkonfiguration.
2. Erstelle für die Staging-Modelle je eine eigene YAML-Dokumentation im `documentation/`-Unterordner.
3. Erstelle für die Core-Modelle je eine eigene YAML-Dokumentation im `documentation/`-Unterordner.
4. Erstelle für das Mart `mart__order_summary` eine YAML-Dokumentation im `30_marts/documentation/`-Ordner.
5. Setze Modell-Tags (`tpch`) und Spalten-Tags (`pii`) gemäß Vorgabe.
6. Führe `dbt docs generate` aus und prüfe den Lineage-Graph.

## Abnahmekriterien

- `dbt docs generate` läuft fehlerfrei.
- Dokumentationen sind für Staging/Core/Marts vorhanden und im Docs-Interface sichtbar.
- Tags auf Modell- und Spaltenebene sind gepflegt.
- Der vollständige Datenfluss von Source bis Mart ist im Lineage-Graph nachvollziehbar.
