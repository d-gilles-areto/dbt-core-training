# Aufgabenstellung Exercise 07

## Ziel

Wiederhole die Kernkonzepte aus Tag 1, behebe gezielt eingebaute Fehler im dbt-Projekt und ergänze ein neues Mart für Umsatz nach Region.

## Aufgaben

1. Starte `dbt run` und behebe die eingebauten Projektfehler iterativ anhand der Fehlermeldungen.
2. Erstelle das neue Modell `mart__revenue_by_region` gemäß vorgegebener Zielabfrage.
3. Führe `dbt run -s mart__revenue_by_region` aus.
4. Prüfe die Ergebnisdaten des neuen Marts.

## Abnahmekriterien

- Alle reproduzierbaren Debugging-Fehler sind behoben.
- `dbt run -s mart__revenue_by_region` läuft erfolgreich.
- Das Mart liefert regionale Kennzahlen (`total_orders`, `total_revenue`, `avg_order_value`).
