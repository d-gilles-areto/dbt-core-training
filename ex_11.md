# Aufgabenstellung Exercise 11

## Ziel

Erstelle einen wiederverwendbaren Custom Generic Test und wende ihn auf mehrere numerische Kennzahlen im Core-Layer an.

## Aufgaben

1. Lege `tests/generic/test_not_negative.sql` mit den Parametern `model` und `column_name` an.
2. Implementiere die Logik: alle Werte `< 0` sollen als Fehlerzeilen zurückgegeben werden.
3. Referenziere den Test in der YAML-Dokumentation von `fact__order_lines` für:
   - `net_amount`
   - `extended_price`
   - `quantity`
4. Referenziere den Test in `fact__orders` für:
   - `total_net_amount`
   - `line_count`
5. Führe `dbt test` aus und prüfe die Ergebnisse.

## Abnahmekriterien

- Der Custom Test liegt in `tests/generic/`.
- Der Test ist auf mehrere Spalten in Core-Modellen angewendet.
- `dbt test` zeigt die neuen `not_negative`-Tests und sie bestehen im Dataset 2.
