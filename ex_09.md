# Aufgabenstellung Exercise 09

## Ziel

Nutze Singular Tests, um zentrale Datenqualitätsregeln in SQL abzubilden und auszuführen.

## Aufgaben

1. Lege den Ordner `tests/singular` an.
2. Erstelle einen Test auf negative Preise in `fact__order_lines`.
3. Erstelle einen Test auf Eindeutigkeit von `order_id` in `fact__orders`.
4. Führe `dbt test` aus und interpretiere die Ergebnisse.

## Abnahmekriterien

- Beide Testdateien liegen unter `tests/singular/`.
- `dbt test` erkennt beide Tests.
- Auf dem Clean Dataset schlagen die Tests nicht fehl (0 fehlerhafte Rows).
