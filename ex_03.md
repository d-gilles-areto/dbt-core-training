# Aufgabenstellung Exercise 03

## Ziel

Baue eine neue Orders-Pipeline von Source bis Mart auf und erstelle ein erstes konsumorientiertes Mart-Objekt.

## Aufgaben

1. Ergänze die Source-Definition um `orders_tpch`.
2. Erstelle `stg__orders` mit entfernten TPCH-Präfixen.
3. Erstelle `fact__orders` als Core-Fact mit semantisch benannten Spalten.
4. Erstelle `mart__orders_per_customer`, das die Bestellanzahl je Kunde aggregiert.
5. Führe die Modelle aus und prüfe die Ergebnisse.

## Abnahmekriterien

- `dbt run` läuft erfolgreich.
- `fact__orders` liegt als View in `<target>_core`.
- `mart__orders_per_customer` liegt als Table in `<target>_marts`.
- Das Mart zeigt pro Kunde eine plausible `total_orders`-Metrik.
