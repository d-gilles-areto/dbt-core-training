# Aufgabenstellung Exercise 12

## Ziel

Zeige den Unterschied zwischen Incremental-Append und Incremental-Merge (SCD1) unter fehlerhaften Eingabedaten und behebe Duplikatprobleme in `fact__orders`.

## Aufgaben

1. Lade das Dirty Dataset in das `sources`-Schema.
2. Führe `dbt build` aus und beobachte den erwarteten Test-Fehlschlag auf `fact__orders.order_id`.
3. Analysiere die Duplikate in der Datenbank (`GROUP BY order_id HAVING COUNT(*) > 1`).
4. Stelle `fact__orders` von Append auf Merge um:
   - `materialized = 'incremental'`
   - `incremental_strategy = 'merge'`
   - `unique_key = 'order_id'`
5. Führe `dbt run -s fact__orders --full-refresh` aus.
6. Prüfe mit `dbt test -s fact__orders`, dass der Unique-Test wieder besteht.

## Abnahmekriterien

- Der Build mit Append zeigt nachvollziehbar den Duplikatfehler.
- Duplikate sind per SQL nachgewiesen und verstanden.
- Nach Umstellung auf Merge + Full Refresh besteht der Test wieder.
- `unique_key = 'order_id'` ist im Model gesetzt.
